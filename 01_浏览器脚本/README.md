# 浏览器脚本（Tampermonkey 用户脚本）

两个脚本，两个角色，别装错：

| 脚本 | 装给谁 | 干什么 | 版本 |
|---|---|---|---|
| **意向雷达-评论区助手.user.js** | **客服**（每人自己装） | 扫评论区、标出意向、生成话术、记录已回、导出 CSV | v1.0.7 |
| **获客采集器.user.js** | **运营主管**（1 人） | 抓作品清单、抓各平台私信、导出 CSV 喂工作台 | v1.0.10 |

---

## 安装步骤（两个脚本一样）

### ① 装 Tampermonkey
Chrome 应用商店 / Edge 加载项 搜 **Tampermonkey** → 安装。

### ② 打开权限开关（Chrome 新版必做，不然脚本不执行）
```
地址栏输入  chrome://extensions  回车
→ 右上角「开发者模式」打开
→ 找到「篡改猴」卡片 → 点「详情」
→ 找到「允许运行用户脚本 / Allow User Scripts」→ 打开
→ 点卡片上的刷新图标重载扩展
```

### ③ 装脚本
```
方式一：把 .user.js 文件直接拖进浏览器窗口 → 弹安装页 → 点「安装」
方式二：Tampermonkey 图标 → 管理面板 → 添加新脚本 → 粘贴全文 → Ctrl+S
```

### ④ 关掉所有相关标签页，重新打开
**不是刷新，是关掉重开。** 脚本只在页面打开的那一刻注入，旧标签页收不到。

| 检查 | 应该看到 |

| 采集器面板 | 右侧「📡 作品清单采集 v1.0.10」或「💬 私信采集 v1.0.10」 |
| 两个脚本都在 | Tampermonkey 菜单里能看到两条（各自对应的站点） |

**版本号对不上 = 粘贴的是旧文件。**

### 每个平台的硬限制（不是工具的问题）

- **抖音私信管理**：粉丝数需 > 1 万才有入口；**陌生人的私信 PC 端看不到，只能看 APP**
- **小红书电脑回复**：需装官方「私信通」客户端
- **视频号**：没有网页版广场，只能管自己号的评论和私信
- **快手**：网页版 DOM 结构未在真实页面校准过，**首次使用请先扫一条视频确认**

## 常见问题

### 装了没反应
三个开关逐个查：① Tampermonkey 是否启用 ② 是否开了「允许运行用户脚本」③ 标签页是否在装脚本**之后**打开的。

### 面板在，但评论不标红
① 评论还没加载完 → 往下滚 ② 这条视频真没有意向评论 ③ 面板上的「员工」没填（不影响标红，但影响导出）

### 点评论打不开原来的内容
已修复（v1.0.4 起）。现在点评论正常跳转，只有点右上角小圆点才生成话术。如果还这样，说明脚本是旧版。

### 采集器抓不到
点面板最下面「抓不到？点这里看页面结构」，会显示它找到了什么（多少链接、多少卡片、最佳容器 class）。截图给技术，能精确定位。

### 小红书采集不到
检查脚版本 ≥ 1.0.7。早期版本只写了小红书**后台**域名，主站压根不注入。

## 一条只读原则（别改）

这两个脚本**只读页面、只导出文件，从不发送任何消息**。

所有回复都由员工用自己的账号、自己的手指发出去。这既是账号安全线，也是法律安全线（全自动私信在国内有刑事判例）。
