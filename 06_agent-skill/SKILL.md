# 意向雷达（Agent 版）

**把「翻评论区找客户」这件事交给 Agent。** 扫关键词下的短视频评论 → 按行业词库判 A/B 级 → 写进获客工作台 → 出一张派单表。

人只做两件事：**判断** 和 **用自己的手指回复**。工具永不代发。

## 什么时候用

- 老板说「今天扫一下评论区」「看看谁在问价」「出一张派单表」
- 每天固定时间跑一次获客雷达
- 换行业了，要换词库重扫

## 依赖：ego(lite) 浏览器

本技能靠 `ego-browser`（Citro Labs 的 ego lite）驱动真实浏览器，好处是**继承用户已登录的账号**，不用重新扫码，且 Agent 在独立 Space 里跑、不抢用户标签页。

**安装（Windows，一次）**：

```powershell
# 1) 装浏览器（会弹 UAC，点「是」）
powershell -ExecutionPolicy Bypass -File install\install_windows.ps1

# 2) 首次启动后，在 ego 窗口里完成 onboarding（约 30 秒，必须人点）
#    · 问是否导入 Chrome 数据 → 建议「稍后设置」，然后在 ego 里单独登录要扫的平台
# 3) 新开一个终端（PATH 需要重新加载），验证：
ego-browser nodejs -e "console.log('ego-browser ready')"
```

> ⚠️ **onboarding 必须由人完成一次**（UAC 提权 + 引导页），这是 Windows 的限制，做不到纯静默。装完之后才全自动。

## 跑一次扫描

```bash
cd <这个包所在目录>
python scripts/run.py --keyword 云南旅游 --videos 3 --rounds 2
```

| 参数 | 含义 | 建议 |
|---|---|---|
| `--keyword` / `--keywords` | 搜什么词（逗号分隔可多个） | 用客户真会说的具体词 |
| `--videos` | 每个关键词最多打开几个视频 | 3–5（越多越慢） |
| `--rounds` | 评论区往下滚几屏 | 2–4 屏，约等于 40–80 条评论 |
| `--pack` | 行业包（词库+话术） | 默认 `云南旅游`，见 `packs/` |
| `--platform` | `douyin` / `xhs` / `ks` | 默认取行业包里的 platform |
| `--ego` | ego-browser 路径 | 默认自动找 |

**跑完你会看到**：

```
ego-browser = C:\Program Files\Citro Labs\ego lite\Application\0.6.1.13\ego-browser.exe
行业包 = 云南旅游｜关键词 ['云南旅游']
  「云南旅游」：视频 2｜评论 61｜A 5 B 7
写回工作台：新增 2 条作品 / 更新 0 条 / 清单共 2 条
派单表：派单表_20261029-2201.md
```

## 产出物在哪

| 文件 | 内容 |
|---|---|
| `02_workbench/data/works.json` | 作品清单 + A/B 意向数（**「今日清单」「派单台」两个页面直接读它**） |
| `02_workbench/data/scan_meta.json` | 最近一次扫描的元信息（关键词、条数、时间） |
| `06_agent-skill/out/派单表_*.md` / `.csv` | 给人看的派单表，客服照这个回 |
| `06_agent-skill/out/raw_*.json` | 原始评论（排查用，可删） |

写完 `works.json` 后**不需要手动重建页面**——重开工作台（或双击 `启动工作台.vbs`）即可看到。

## 换行业（用向导，不用手改 JSON）

```bash
python scripts/new_pack.py
```

它会问 4 个问题，然后生成一个能直接跑的包：

| 问题 | 怎么答 | 例 |
|---|---|---|
| ① 行业名 | 一句话 | 电瓶车电池 |
| ② 关键词 | **客户在评论区真的会说的具体词** | 换电池、锂电池、以旧换新 |
| ③ 产品词 | 评论必须提到它才算意向（防止"多少钱"泛词误报） | 电池、电瓶 |
| ④ 平台 | douyin / xhs / ks | douyin,xhs |

生成后自动带了 52 个强意向词、26 个兴趣词、10 条话术骨架，并可以选「同步写进工作台的话术库/需求池」（旧文件自动备份）。

**一行式（给 Agent 或脚本用）**：

```bash
python scripts/new_pack.py --name 电瓶车电池 --keywords 换电池,锂电池 --prod 电池 --platform douyin,xhs
```

### 关键词填错 = 白扫（实测教训）

我拿 `换电池` 试跑了一次，扫出来 33 条评论，**A/B 全是 0**——因为出来的是「手机换电池」的维修视频，评论在问"sim 卡故障找谁"。

**不是工具坏了，是关键词太宽。** 换成"电瓶车电池 / 锂电池以旧换新"才对。

**原则：填客户真会说的具体词，不要填行业大类。**

### 生成的词是草稿

向导给的是**通用销售词 + 行业名话术骨架**，它不知道这个行业的真实痛点。

**接单后必做**：拿客户账号扫 200–300 条真实评论 → 看客户到底怎么说话 → 把真实表达补进 `a_words`。

云南那套「高反 / 带老人 / 纯玩不购物」就是从真实评论区里长出来的，不是想出来的。

## 红线（不可越过）

| 项 | 规则 |
|---|---|
| **发送** | 永不代发。评论/私信都由人的手发出去 |
| **采集** | 只在真实登录的浏览器里只读页面 |
| **数据** | 只记昵称、评论原文、作品链接；不抓手机号/UID/批量主页 |
| **频率** | 小红书普通号 ~5 人/天；抖音同一陌生人 24h 只 1 条 |
| **内容** | 评论/私信里不发微信号、手机号、二维码 |

全自动「扫评论 + 自动私信」在国内有刑事判例。这条线不是保守，是保命。

## 排错

| 现象 | 原因 | 解决 |
|---|---|---|
| `Cannot capture a screenshot while the window is minimized` 或页面空白/抓不到评论 | **ego 窗口被最小化了**，标签页被浏览器节流，页面不渲染 | 把 ego 窗口恢复（不能最小化），再跑 |
| `Please complete the onboarding process first` | ego 没走完引导 | 打开 ego → 完成引导 → 重开终端 |
| `ego-browser` 命令找不到 | PATH 未生效 | 新开终端；或用 `--ego <完整路径>` |
| 评论区抓到 0 条 | 该视频评论未展开/被限流 | 加大 `--rounds`；换 `--videos`；确认账号已登录 |
| 命中很少（A 只有 1–2 条） | 词库太书面 | 扫 200 条真实评论，把口语补进 `a_words` |
| 明显误报（如「不要打广告」被标 A） | 缺否定词 | 把词加进 `neg_patterns` |

## 平台支持现状

| 平台 | `--platform` | 状态 | 说明 |
|---|---|---|---|
| 抖音 | `douyin` | ✅ 已验证 | 实测滚动加载正常（10→19→29 条/视频） |
| 小红书 | `xhs` | ✅ 已验证 | 滚动容器是 `.note-scroller`，实测 10→17→29 条 |
| 快手 | `ks` | ⚠️ 部分打通 | 搜索→卡片→真实鼠标点击→播放器浮层都通了，但**快手网页版的浮层里不加载评论列表**（结论见下） |

**三个平台都要分别登录。** ego 里每个平台各一个标签页，扫码一次即可（登录态保存在 ego 的浏览器 profile 里）。未登录时脚本会直接报「需要先登录 X」并退出——不会给你一堆空结果。

**小红书注意**：它风控比抖音凶，会提示「电脑设备登录超限」。遇到就先在手机端「设置 → 账号与安全 → 登录设备管理」退掉多余设备，再扫码。小红书建议**一天 1–2 次、每次 2–3 个笔记**，频率拉高大概率封号。

### 快手为什么卡住（实测结论）

搜索页能拿到 19 个 `.photo-card`，也用真实鼠标事件成功点开了视频浮层（播放器、赞数、进度条都出现），但：

- 右侧 `.side-area` 里只有「评论 / TA 的作品」两个 tab 导航，**评论列表是空的**
- 页面显示「1131 赞 73 评论」，浮层里却只有「0 评论」——评论被网页版有意不加载
- 卡片上没有 `photoId` 属性、没有 `href`，拿不到独立详情页地址

**下一步要走的路**：改从 `cp.kuaishou.com`（快手创作者平台）拿自己作品的评论，或换移动端 UA。这需要重新探一遍入口，不是改选择器能解决的。

## 已知限制

- 小红书/快手的评论容器、卡片选择器是按通用结构预置的，**首次使用需按真实页面校准一次**（改 `run.py` 的 `PLATFORMS` 字典即可，不用动流程代码）。
- 抖音搜索结果卡片必须 `force` 点击（缩略图会拦指针）——已在模板里处理。
- 抖音 `comment-item` 内嵌作者回复，必须按「作者」徽章切段，否则会把整条判成作者本人。
- 单关键词 2 个视频约 2–4 分钟；`--videos 5` 请留 10 分钟。
