# 意向雷达 · Agent 版（SKILL 包）

> **把一个文件夹拷到任何一台电脑，交给那台电脑上的 AI Agent，它就能自己扫评论区、挑出想买的人、把结果写进获客工作台。**
> 人只做两件事：**判断** 和 **用自己的手指回复**。

---

## 这个包解决什么

以前：客服和运营各装一个油猴脚本 → 人开着页面刷 → 导出 CSV → 拖进工作台。
现在：**Agent 用真实登录的浏览器在后台自己扫**，扫完直接写库。

```
关键词 → 短视频 → 评论区 → 按行业词库判 A/B 级 → 写进工作台 → 出派单表
```

---

## 三步装好（一台新电脑）

```
① 装依赖（一次）：
   install\install_windows.ps1   ← 右键「使用 PowerShell 运行」
   会装 ego(lite) 浏览器，最后要求你在弹窗里点几下完成引导（约 30 秒）

② 交给 Agent：把本文件夹路径告诉它，让它读 SKILL.md

③ 换行业（可选，第一次用必做一次）：
   python scripts\new_pack.py     ← 问 4 个问题，生成你的行业包

④ 跑一次：
   python scripts\run.py --keyword 云南旅游 --videos 3 --rounds 2
```

看到类似这行就成功了：

```
「云南旅游」：视频 3｜评论 87｜A 14 B 9
写回工作台：新增 1 条作品 / 更新 2 条
```

## 包里有什么

| 路径 | 作用 |
|---|---|
| `SKILL.md` | **给 Agent 看的说明书**（它能自己读完就干活） |
| `install/install_windows.ps1` | 一键装 ego(lite) + 记录路径 |
| `install/egoliteSetup.exe` | ego(lite) 安装包（19MB，官方原版，sha256 `dc1bcf9c…5d4`） |
| `scripts/run.py` | **主入口**：扫描 → 判级 → 写工作台 → 出派单表 |
| `scripts/new_pack.py` | **行业包向导**：问 4 个问题，生成能直接跑的行业包（不用手改 JSON） |
| `scripts/scan_template.mjs` | 浏览器侧采集脚本（抖音搜索→视频→评论） |
| `scripts/judge.py` | 判级器（A/B/R + 话术匹配） |
| `packs/云南旅游.json` | 现成行业包（49 个 A 词 / 31 个 B 词 / 18 条话术） |
| `packs/_template.json` | 换行业的空白模板 |

## 三条底线（写死在设计里）

1. **永不代发** —— 评论和私信都由人的手发出去。全自动私信在国内有刑事判例。
2. **只读采集** —— 只在真实登录的浏览器里读页面，不做服务器爬虫。
3. **只记必要信息** —— 昵称、评论原文、作品链接；不抓手机号/UID/批量主页。

## 支持哪些平台

| 平台 | 参数 | 状态 |
|---|---|---|
| 抖音 | `--platform douyin` | ✅ 已验证（滚动加载正常） |
| 小红书 | `--platform xhs` | ✅ 已验证（10→17→29 条实测） |
| 快手 | `--platform ks` | ⚠️ 部分打通：能搜到视频、能打开播放器，但网页版浮层不加载评论列表 |

快手的问题不在选择器，在入口：快手网页版把评论藏起来了（搜索浮层只显示"0 评论"，卡片也没有 photoId）。下一步要改走创作者平台。详见 `SKILL.md`。

```bash
python scripts\run.py --platform xhs --keyword 云南旅游 --videos 2 --rounds 2
```

**每个平台都要单独登录一次**（ego 里各开一个标签扫码）。没登录时脚本会直接告诉你「需要先登录 X」，不会给你空结果。

## 已知限制（别踩）

- **目前只有 Windows 版安装脚本**（ego lite 本身 Win/Mac 都有，Mac 装法见官网）。
- **ego 窗口不能最小化** —— 最小化后标签页被节流，页面不渲染，扫出来是空的。
- **引导必须人点一次**（UAC + onboarding），做不到 100% 静默。每个平台还要各扫一次码。
- **小红书风控比抖音凶**：会出现「电脑设备登录超限」，需先在手机端退掉多余设备；建议一天 1–2 次、每次 2–3 个笔记。
- 词库是草稿：真实命中率要靠扫 200–300 条真实评论后补口语词。
