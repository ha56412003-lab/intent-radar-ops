# 获客工作台

> 本地看板。纯 Python 标准库，**零第三方依赖**，数据是明文 JSON/CSV。
> 双击 `启动工作台.vbs` → 浏览器打开 http://127.0.0.1:8790/

---

## 启停

| 操作 | 做法 |
|---|---|
| 启动 | 双击 **启动工作台.vbs**（静默启动，2 秒后自动开浏览器） |
| 停止 | 双击 **停止工作台.vbs** |
| 换端口 | 命令行 `python serve.py 8791` |

**不要双击 site 里的 html 文件。** 那样打不开服务接口，读不到数据、也不能一键换行业。

**不设开机自启** —— 用的时候点一下就好。

---

## 八个页面，每个只回答一个问题

| 页面 | 回答什么 | 谁看 |
|---|---|---|
| **总台** | 今天有多少活、昨天转化怎么样 | 老板每天第一眼 |
| **今日清单** | 今天该扫哪些作品（播放/评论数/已识别意向/派给谁） | 运营主管 |
| **派单台** | 谁扫哪条、谁快到限额了（防封号） | 运营主管 |
| **私信承接** | 私信进来的人跟到哪一步、下一步做什么 | 客服/老板 |
| **漏斗复盘** | 三个转化率哪个漏了（回复率 / 回复→私信 / 私信→留资） | 老板 |
| **需求池** | 客户在问什么 → 该做什么内容 | 内容/运营 |
| **话术库** | 哪句话有效（发了多少、回了多少、回复率） | 客服/运营 |
| **行业包** | 换行业：填关键词 → 出全套包 | 负责人 |

## data/ 目录就是数据库

| 文件 | 存什么 | 谁维护 |
|---|---|---|
| `works.json` | 作品清单（链接、播放、评论数、A/B 意向数、负责人、状态） | 运营主管 |
| `staff.json` | 员工与账号、每日回复限额 | 一次配好 |
| `leads.json` | 线索池（客户、阶段、下一步、跟进人） | 有人私信就加 |
| `demands.json` | 需求池（客户问题、出现次数、对应选题） | 扫评时顺手记 |
| `scripts.json` | 话术库（场景、话术、发了多少、回了多少） | 换行业时自动生成 |
| `_incoming/` | **多人导出的 CSV 汇总入口** | 全员丢这里 |

**支持的文件名前缀**（其他文件会被忽略，不会误读）：
```
回复记录_*.csv    客服的雷达导出
works_*.csv       运营主管的作品清单
inbox_*.csv       运营主管的私信采集
replies_*.csv     旧命名，兼容保留
```

## 换行业（不写代码）

工作台第 8 页「🎁 行业包」：
```
填行业名 + 关键词 → 生成 → 下载雷达包/采集包 → 点「一键应用到工作台」
```

「一键应用」会自动：
1. 把整个 `data/` 备份到 `data\_backup_时间戳\`
2. 写入 `scripts.json` / `demands.json` / `staff.json`
3. 清空 `works.json` / `leads.json`
4. 删掉上个行业的 CSV
5. 重新构建 8 个页面

**安全网**：三个文件一个都没写成功 → 直接报错返回，**绝不动老数据**。

回滚：把 `data\_backup_xxx\` 里的文件拷回 `data\`。

## 给客户演示

`site/` 目录里是纯静态 HTML —— **整个文件夹拷给客户，双击就能看**，不用装任何东西。

⚠️ 演示前把 `data/` 换成演示数据，别把真实的客户信息发出去。

## 技术说明

| 文件 | 作用 |
|---|---|
| `build.py` | 读 `data/` → 生成 `site/*.html`（纯标准库） |
| `serve.py` | 本地 HTTP 服务（127.0.0.1:8790）+ 行业包写入接口 |
| `启动工作台.vbs` | 自动找 Python → 构建 → 起服务 → 开浏览器 |
| `停止工作台.vbs` | 关掉占用 8790 的进程 |

**写入接口**：`POST /api/apply-industry`，只接受本机、只允许写三个白名单文件、写前自动备份。

**Python 路径**：启动器会自动找（PATH → 常见安装目录 → 项目内 `.python-path` 文件）。
如果机器上装了多个 Python 且想指定，在 `.python-path` 里写一行完整路径即可。

## 排错

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击 vbs 弹「没找到 Python」 | 没装或没加 PATH | 装 Python 3.9+，勾 Add to PATH |
| 浏览器打不开 8790 | 服务没起来/端口被占 | 停止再启动；或看 `python build.py` 的报错 |
| 数据没更新 | CSV 没放进 `_incoming\` | 把 CSV 拖进去，重开工作台 |
| 换行业后还是旧内容 | 没点「一键应用」 | 第 8 页重新点一次 |
| 页面样式全乱 | 用了很老的浏览器 | Chrome/Edge 最新版 |
