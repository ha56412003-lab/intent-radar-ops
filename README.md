# 获客系统 · Intent Radar Ops

> **AI 帮你看评论区，挑出想买的人；员工只负责回。**
> 一套零依赖、纯本地的获客作业系统 —— 把「找客户 → 判意向 → 人工触达 → 私域承接 → 数据复盘」做成流水线。

```
抖音 · 小红书 · 快手 · 视频号
        ↓  脚本只读扫描
   自动标出「谁在问价、谁能成交」
        ↓  员工用自己的号回
   私信 / 留资 / 成交
        ↓
   漏斗看板告诉你哪一段漏了
```

---

## 这套东西解决什么问题

| 你的处境 | 系统怎么接住 |
|---|---|
| 一条视频 3000 条评论，翻不完 | 脚本自动扫，只把 **A 级 13 条 / B 级 19 条**留给你 |
| 说不清谁是真想买 | 按行业词库打分：A（当天回）/ B（48h 回）/ C（不理会）/ R（高风险别接） |
| 每条回复都从零想话术 | 点评论旁的小圆点，按场景自动出草稿，改两句就发 |
| 不知道哪句话有效 | 话术库带「发了多少 / 回了多少 / 回复率」 |
| 不知道客户到底在问什么 | 需求池：同一个问题被问 ≥3 次 → 该做成内容 |
| 员工干了多少不知道 | 派单台按人统计；导出 CSV 带员工名，不会互相覆盖 |
| 换个行业要重做一遍 | **行业包生成器**：填关键词 → 10 分钟出全套包，代码不用改 |

## 5 分钟跑起来

```
1) 装 ego(lite) 浏览器（一次）：
   install\install_windows.ps1 → 右键「使用 PowerShell 运行」
   最后在弹出的 ego 窗口里点几下完成引导（约 30 秒）
2) 让 Agent 扫一次：
   python scripts/run.py --keyword 云南旅游 --videos 3 --rounds 2
3) 双击 02_workbench\启动工作台.vbs
4) 浏览器打开 http://127.0.0.1:8790/  ← 「今日清单」「派单台」里已经有数据了
```

**不需要再装 Tampermonkey，也不需要任何人导出 CSV。**
完整的包使用说明见 `06_agent-skill/README.md`；给 Agent 看的说明书是 `06_agent-skill/SKILL.md`。

详细步骤见 **[快速开始.md](快速开始.md)**。

**前提**：装了 Python 3.9+（[下载](https://www.python.org/downloads/)，安装时勾选 Add to PATH）。不需要 pip、不需要数据库、不需要联网。

## 谁用哪一部分

| 角色 | 装什么 | 干什么 |
|---|---|---|
| **Agent**（一台机器） | `06_agent-skill` + ego(lite) | 每天自动扫评论区、判意向、写进工作台、出派单表 |
| **客服**（可多人） | **什么都不装** | 打开工作台看「派单台」→ 用自己手机逐条回 → 更新状态 |
| **老板 / 负责人** | 工作台 | 看漏斗、看线索、看每个人的产出 |

多人多机的配法见 **[04_docs/7机部署指南.md](04_docs/7机部署指南.md)**。

## 换行业：不用改代码

工作台第 8 页「🎁 行业包」：

```
填行业名 + 行业关键词（客户真会说的词）
→ 自动生成 A/B/R 级词 + 话术骨架（可手改）
→ 下载 📡 雷达包（给客服）+ 📋 采集包（给运营）
→ 点「⚡ 一键应用到工作台」→ 数据自动换成新行业
```

**关键设计：产品词闸门。** 评论必须提到你填的产品词，才算意向——避免「多少钱」这种泛词把无关评论全标红。
真实案例：评论「我的电动车电池跑不远了，能修吗」→ 提到产品 ✅ + 提到「能修吗」✅ → A 级。

## 合规底线（这条比功能重要）

| 项 | 红线 |
|---|---|
| **发送** | 工具**永不代发**。每一条都由人的手指发出去 |
| **采集** | 只在员工真实登录的浏览器里**只读**页面，不做服务器爬虫 |
| **数据** | 只记录昵称、评论原文、作品链接；不抓手机号、UID、批量主页 |
| **频率** | 小红书普通号 ~5 人/天、专业号 ~20 人/天；抖音同一陌生人 24h 只 1 条 |
| **内容** | 评论/私信里不发微信号、手机号、二维码 |

**为什么这么严**：全自动「扫评论 + 自动私信」在国内有刑事判例（提供侵入计算机信息系统程序罪），平台群控批量私信封禁率高达 75%。这套系统选的是唯一既能跑量又不违法的形态。

## 平台支持

| 平台 | 广场扫评论 | 作品清单采集 | 后台私信采集 | 备注 |
|---|---|---|---|---|
| 抖音 | ✅ | ✅ | ✅ | 私信管理需粉丝 >1万；陌生人私信 PC 端不可见 |
| 小红书 | ✅ | ✅ | ✅ | 电脑回复需官方「私信通」客户端 |
| 快手 | ✅ | ✅ | — | 按通用规则接入，真实页面首用请先验证一条 |
| 视频号 | ❌ | — | ✅ | 无 Web 广场层，只能管自己号的评论/私信 |

## 最后一句

**工具不产生客户，只放大人的动作。**

这套系统能把你从「翻 3000 条评论」里救出来，但它不能替你判断哪个客户值得跟、不能替你说话。

**它唯一的价值，是让你每天多回 5 个真客户，而不是把时间耗在翻评论上。**
