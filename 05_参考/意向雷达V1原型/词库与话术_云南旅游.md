## 话术模板（AI 起草用底稿，员工可自由改）

> 合规规则内置：任何话术不得含微信/手机号/二维码/站外链接；引导方向只能是"私信细聊 / 看主页 / 留资卡片"

### A-拼团/结伴类
```
我们有固定发团的纯玩小团，你大概几号方便、几个人？我看看能不能给你拼上，行程表发你看看～
```

### A-问价格类
```
费用看人数和天数差别挺大的。你们几个人、想去哪几个地方？我按你的情况发一份明细给你，纯玩无购物的～
```

### A-带老人/亲子类
```
带老人完全没问题，我们专门排过慢节奏版本：每天车程控制在 2 小时内、不早起、景点都选不用爬坡的。告诉我老人年纪和天数，我给你排一版～
```

### A-定制/包车类
```
可以定制。你们几个人、玩几天、想不想去雨崩/泸沽湖这种远线？我按你的节奏排一版行程和报价～
```

### B-求攻略类
```
我主页合集里有按天数分的攻略（2天/5天/环线版），你可以先看看，看完有不清楚的随时问我～
```

### B-避坑类
```
云南玩得舒不舒服主要看三件事：行程节奏、有没有隐形购物、司机服务。我写了一篇避坑清单在主页，可以先对照着看～
```

### 高反焦虑类（云南特有，转化率最高的恐惧点）
```
怕高反的话，行程顺序很关键：先昆明→大理（海拔低）适应两三天，再上丽江/香格里拉，基本都不会有反应。我们带过 70+ 的客人走完全程，需要的话我发你防高反行程安排～
```

## 平台账号规则速查（贴在员工工位）

| 平台 | 主动私信陌生用户上限 | 备注 |
|---|---|---|
| 小红书普通号 | **5 人/天** | 对方未回复则不能再发 |
| 小红书专业号 | **20 人/天** | 建议公司注册专业号 |
| 抖音 | 对方未关注前，24h 内同一人仅 1 条 | 引导站外（微信/二维码）= 违规 |

**万能安全话术结尾**：`细节我私信里跟你说～`（把对话引到私信，用官方留资卡承接）
