# 获客系统 · 7 台电脑部署指南

> 1 台运营主管 + 1 台老板 + 5 台客服，怎么用同一套系统。
> 核心问题只有一个：**数据汇到哪儿**。三种做法，选一个。

---

## 一、角色分工（先明确谁干啥）

| 机器 | 装什么 | 职责 | 每天产出 |
|---|---|---|---|
| **运营主管 ×1** | 采集器（v1.0.9） | 抓作品清单 → 派单；抓各平台私信 | `works_*.csv`、`inbox_*.csv` |
| **客服 ×5** | 雷达（v1.0.6） | 扫评论 → 回复 → 标记已回 | `回复记录_<员工名>_<日期>.csv` |
| **老板 ×1** | 工作台（8 页面） | 看漏斗、看线索、看转化率 | 无（只读） |

**所有 CSV 都要落到同一个"汇总处"，老板的工作台读那一个地方。**

---

## 二、方案 A：云同步盘（推荐先上，今天能配好）

### 适合
客服不在同一间办公室、有人在外跑、不想折腾内网。

### 配法

**第 1 步：老板电脑（一次）**
```
① 装坚果云 / OneDrive / 企业微信微盘（任选，全公司用同一个）
② 建一个共享文件夹，比如  获客数据
③ 把整个「获客工作台」文件夹放进去：
      获客数据\获客工作台\
④ 打开共享权限，把 5 个客服 + 运营主管都拉进来
```

**第 2 步：客服电脑（5 台，各做一次）**
```
① 装同一个云盘客户端，登录，等 获客数据 文件夹同步下来
② 装 Tampermonkey + 雷达脚本（v1.0.7）
③ 面板上点「员工：xxx」→ 填自己的名字（重要！导出的文件名靠它区分）
④ 收工时点「导出记录 CSV」→ 弹出【另存为】窗口
   → 第一次导航到：  获客数据\获客工作台\data\_incoming\
   → 点保存。以后 Chrome 会默认停在这个位置，每次点保存即可。
```

**注意：不需要改浏览器默认下载目录。** 用的是「另存为」对话框，你自己平时下别的文件该去哪还去哪。

**第 3 步：运营主管电脑（1 台）**
```
① 同上装云盘客户端
② 装 Tampermonkey + 采集器（v1.0.10）
③ 导出时同样走「另存为」，选到同一个 _incoming\ 文件夹
```

**第 4 步：老板每天怎么用**
```
双击   获客数据\获客工作台\启动工作台.vbs
→ 浏览器打开 http://127.0.0.1:8790
→ 看到的已经是全公司汇总后的数据
```

### 为什么能自动汇总
```
客服导出 CSV → 落到 _incoming\ → 云盘自动同步 → 老板电脑上就有
工作台启动时自动读 data\ 和 data\_incoming\ 两个目录
```

### 实测验证
```
基线 8 条回复
+ 张三导出 1 份  → 16 条  ✅
+ 再 4 个客服各 1 份 → 48 条  ✅（5 人并发不覆盖、不丢失）
```

## 三、方案 B：局域网共享盘（全部人在同一办公室）

### 配法
```
① 选一台常开的电脑当"数据机"（建议运营主管那台）
② 把「获客工作台」文件夹共享出来：
      右键文件夹 → 属性 → 共享 → 高级共享 → 勾选"共享此文件夹"
      权限给"读取/更改"
③ 其他人用网络路径访问，比如：
      \\192.168.1.20\获客工作台\data\_incoming\
④ 浏览器下载位置设成这个网络路径
⑤ 老板双击共享盘里的 启动工作台.vbs
```

**注意**：数据机要开着，关机就同步不了。这是方案 B 最大的缺点。

## 四、方案 C：内网服务器版（客户多了再上）

一台常开机器跑工作台，绑定内网 IP，**客服浏览器直接打开工作台页面**，页面上点「上传我的记录」——不用改下载目录。

需要改造（约 1 天）：
- serve.py 绑定 `0.0.0.0`（允许局域网访问）
- 加 `/api/upload-replies` 上传接口
- 加一个"上传我的记录"页面
- 建议加个简单口令，防止同网段的人乱看

**现在不做，等客户数上来了再说。** 现在 7 台机器的数据量，云盘完全够。

## 五、每天的操作流（云盘方案）

```
早上 运营主管
  搜关键词 → 采集器「采集当前页」→ 导出 → 自动进 _incoming\
  → 在工作台「派单台」把作品派给客服

白天 5 个客服（各自电脑）
  打开被派的作品 → 雷达自动高亮 → 点小圆点出话术 → 复制改两句
  → 评论区回复 → 点「已回复 ✓」
  收工：点「导出记录 CSV」→ 自动进自己的 _incoming\ → 自动同步

老板（随时）
  双击启动工作台 → 看总台 / 漏斗复盘 / 私信承接
  想细看谁干了多少 → 派单台（按员工统计）
```

## 六、四个必须注意的点

| 坑 | 说明 |
|---|---|
| **员工名必须填** | 客服面板上「员工：xxx」不填，5 个人的文件会叫同一个名字，云盘会覆盖 |
| **别改导出文件名** | 工作台只认这几个前缀：`回复记录_*` / `works_*` / `inbox_*`，改名就读不到 |
| **另存为选对文件夹** | 第一次务必选到 `_incoming\`；以后 Chrome 会记住，但如果哪天保存到了别处，手工拖回 `_incoming\` 即可 |
| **云盘冲突** | 每个人文件名带自己名字，不会冲突；如果看到"冲突副本"文件，删掉重复的即可 |
